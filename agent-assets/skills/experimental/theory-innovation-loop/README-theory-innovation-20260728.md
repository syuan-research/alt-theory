## Added mid-session: 2023 practice evidence

Owner pointed to the Frontiers supplementary conversations
(`0 Research Projects/ChatGPT/Frontiers of Psych/Revision 5/`,
Sheets 1–3 read). Process moves — not prompts — were folded into the
skill md: cases→aspects as an alternate diverge entry; story schema
(who/when/what/felt); counter-examples as a first-class diverge move
(2023 observation: negative batches came out MORE diverse than
positive ones); CAN/CANNOT paired fit-testing; residual-case check as
the deductive→inductive gate that produced new concept candidates;
vague-concept grounding across the case pool; user-synthesis audit.

What survives vs. what the agent era changes (condensed; full analysis
in session chat): the epistemic moves survive because their bottleneck
is user recognition/judgment, not information access. The 2023
transcripts are a manual trace of the workflow — the user WAS the loop
engine, carrying state and doing every converge by hand — which is
evidence the workflow is real, not invented. What changes: state
ledgers and judge subagents take over the mechanical carrying;
internet access makes the deductive matching verifiable (2023 matching
was parametric-only); the persona-framing custom instructions are
obsoleted by role md. What must NOT be automated away: the user's
reality-grounded pushback at batch boundaries (measurability,
feasibility, "not quite that") — the 2023 sessions worked because the
user read and reacted to every batch; scaling generation without
preserving those contact points would remove the mechanism. Also
noted: the 2023 AI-side content is generic by today's standards — the
value is the user-side move sequence; moves are a library, not a
mandatory pipeline (e.g. user-synthesis audit was partly a weak-model
workaround; deploy on occasion, don't ritualize).

## Added mid-session: ARS academic-paper-reviewer inspiration

(`academic-writing-exp/local-skills/academic-research-skills/academic-paper-reviewer/`),
whose simulated reviewers are much better than the current
workstream-b sim-user/reviewer settings. Mechanisms adopted into the

user-adjustable cards as the earliest gate; a devil's-advocate seat

traceability (no invented consensus). Deliberately not taken: 7-agent
fixed team, phase contracts, schema validators, template library.

a direct upgrade path for workstream-b's sim-user/reviewer settings —
generic personas there have the same drift problem the owner already
observed.
