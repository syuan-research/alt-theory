# Commands

Typing `/` in the composer opens the **command palette** — the complete
list of what can be invoked by name, self-documenting as you type.

## What lives there

- **Every active skill**, invocable as `/skill-name` — the reliable way
  to apply a specific method right now, bundled or your own.
- **Conversation commands**:
  - `/branch` — branch this conversation from here;
  - `/btw` — open a side conversation carrying current context;
  - `/new` — start a new conversation;
  - `/compact` — compact this conversation now, at a resting point you
    choose rather than when the limit forces it.

The palette filters as you type, and each entry shows what it does — it
teaches itself, which is why the Toolbox's "All skills…" entry simply
drops you here.

## Commands versus sentences

Nothing in the palette is the only way to do its thing. "Let's branch
here", "align with me before we start", "summarize this conversation"
work as plain sentences — the palette exists for precision (this skill,
exactly), for speed, and for discovering what is available. Use
whichever fits the moment; the agent treats an explicit command as an
instruction, not a suggestion.
