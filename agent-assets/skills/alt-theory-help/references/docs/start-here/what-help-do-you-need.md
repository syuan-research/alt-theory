# What Kind of Help Do You Need?

You have the basics. Where you go next depends on what you are trying to
do.

## "I want to see what it can do for my research"

Read [Using the Alt Theory App](../README.md#using-the-alt-theory-app) —
three pages organized by the kind of work you are doing:

- [When Understanding Is the Goal](../using-the-app/when-understanding-is-the-goal.md) —
  exploring, examining concepts, building understanding.
- [Think Better at Key Moments](../using-the-app/think-better-at-key-moments.md) —
  design, review response, restructuring: judgment-heavy moments.
- [When Concrete Work Is the Main Task](../using-the-app/when-concrete-work-is-the-main-task.md) —
  producing, searching, working through files.

## "I want to understand or set up a specific feature"

The [System Guide](../README.md#system-guide) documents every feature
canonically: what it is, how to use it, how to verify what is active, and
how to recover when something goes wrong.

## "I already run an agent harness" / "I want to integrate or customize"

[Advanced Use, Integration, and
Customization](../README.md#advanced-use-integration-and-customization)
covers plugins, cross-harness continuity, configuration ownership and
precedence, and the boundaries for modifying the product itself.

## "Something is wrong"

- Feature-specific problems: check that feature's System Guide page — each
  has verification and recovery sections.
- Problems that cross features, or you are not sure where it belongs:
  [Troubleshooting](../help/troubleshooting.md).
- Quick questions: [FAQ](../help/faq.md).

## Ask inside the app

The **Helper** is a built-in assistant for questions about Alt Theory
itself — it starts fresh (it does not read your current conversation) and
answers from the product's current documentation, including guided setup
in plain language. Find it in the Toolbox. When it cannot verify
something, it says so and points here rather than inventing steps —
[Helper and In-App Guidance](../system-guide/helper-and-guidance.md).

For anything beyond the docs — bugs, feedback, research collaboration —
see [Releases and Further Help](../help/releases-and-further-help.md).
