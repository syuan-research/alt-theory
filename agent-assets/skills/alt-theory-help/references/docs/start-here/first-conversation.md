# Start Your First Conversation

## The empty screen

A new conversation starts from a simple screen: a greeting, two **mode
cards** — Understand and Work — and the message composer. Around the
composer you will find:

- the **model chip**, showing which AI model this conversation will use;
- the **role picker**, for optional presentation styles — none is a fine
  default ([what roles are](../system-guide/settings-and-configuration.md));
- the **knowledge base picker**, for optional curated reference material;
- the **Toolbox**, a small menu of the app's featured actions.

You do not need to configure any of this now. The defaults are chosen so
that a first conversation just works. Pick **Understand** — careful
dialogue, nothing touches your files — and start typing.

## A first prompt worth sending

Alt Theory shows its character best on real, unfinished thinking — the
kind of question you might hesitate to ask a colleague because it is not
fully formed yet. For example:

> I'm interested in why people keep using parks differently after a
> renovation, but I can't tell if my question is about place attachment,
> habit, or something else. Can you help me figure out what I'm actually
> asking?

A general chatbot would hand you a framework. Alt Theory will more likely
slow down: distinguish the nearby concepts, ask what you have observed,
point out what each framing would commit you to, and mark what it is
unsure about. That slower movement is the product working as intended.

## What you are looking at

While the agent responds you may see, depending on the conversation:

- **Thinking** — a collapsible block showing the model's reasoning before
  its answer.
- **Tool lines** — one-line entries when the agent reads a file, runs a
  search, or uses a skill, so its actions are visible rather than implied.
- The response itself, with tables and diagrams rendered where the agent
  uses them.

You can **stop** a response at any time with the stop control — nothing
breaks, and the conversation continues from wherever you take it next.

## If you are new to AI agent tools

Two things are worth knowing from the first minute:

- In Understand mode, the agent cannot reach the network, and it touches
  no file you have not attached — anything beyond that boundary asks you
  first. What you paste or attach is what it sees.
- Nothing you do here is irreversible. Conversations can be stopped,
  redirected, revisited, and picked up later — see
  [Continue, Change Direction, and Return Later](continue-and-return.md).
