# Bring in Your Materials and Context

Research conversations are about something — notes, drafts, data, papers.
This page is the minimum you need to know about getting yours in.

## The pieces, in one screenful

- A **conversation** is where you and the agent think and work. It keeps
  its own history and configuration.
- A **file attachment** puts a specific file in front of the agent for
  this conversation — drag it into the composer or use the attach button.
- A **working folder** (Work mode) is a folder on your computer the agent
  can work in: read the files, and create new ones. Attaching a folder is
  an intentional act — it defines where the practical work happens.
- A **knowledge base** is curated reference material — enable it when its
  domain is relevant, and the agent can consult it.

These compose naturally: a conversation might have your draft attached, a
project folder as its working folder, and a knowledge base enabled — or
none of the above.

## What the agent sees, and how to check

The agent sees what you have brought into the conversation — attachments,
the working folder's contents, the enabled knowledge base — plus what you
write. It does not see the rest of your computer. If you are unsure what
is currently attached or active, the composer area shows the working
folder and knowledge base for this conversation, and you can always ask
the agent — "what can you currently see?" is a normal question, and the
answer will tell you which files it has actually read, not a vague
assurance.

## Real files, treated with care

Alt Theory reads the formats research actually uses — Word, PDF, Excel,
PowerPoint — and converted copies appear alongside originals with a
`_converted` suffix, so the pairing is visible.

One convention matters enough to state on a starter page: **your original
files are never edited in place.** When the agent revises a document, it
works on a copy or produces a new clearly-named file and tells you which
file it wrote. Your files remain yours.
