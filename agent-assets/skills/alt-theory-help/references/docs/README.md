# Alt Theory Documentation

Alt Theory is a research workspace for the social sciences. It pairs
careful, honest AI dialogue with the ability to act on your materials when
the work calls for it — in the same conversation.

These docs cover the current release line of the Alt Theory app. Alt Theory
is in active alpha development; behavior described here reflects the
documented release, and known limitations are listed rather than hidden.
