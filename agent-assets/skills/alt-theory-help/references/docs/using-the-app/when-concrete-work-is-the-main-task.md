# When Concrete Work Is the Main Task

Sometimes the next step is simply work: find and verify the references,
read the PDFs, convert the slides, draft the section, revise the document,
work through the project folder. This is Work mode's home ground — agentic
action on your materials, under the same standard of honesty as
everything else. (Same note as this section's other pages: a goal, not a
mode — though this goal does normally need Work.)

## What changes when discussion becomes action

Attach a [working folder](../system-guide/working-folders-files-paths.md)
and the conversation gains a place to act. From there, the practical
differences from a chat tool are visible on every turn:

- **You see what it does.** Each action appears as a line in the
  conversation — which file was read, what was written, which command ran,
  which skill was used — expandable when you want the detail.
- **You see what changed.** A turn that touched files ends with a card
  naming them, with additions and removals counted; new prose shows a
  preview, edited prose shows before/after passages, code shows a diff.
- **Boundaries ask first.** Reading outside your folders, going to the
  network, installing anything — each surfaces an approval request stating
  what is being asked. Denying is safe.
- **Your originals stay yours.** Revisions happen on copies or new,
  clearly named files, and the agent tells you which file it wrote.

## Searching and citing like it matters

Literature work is where fabricated confidence hurts most, so it is where
the discipline is strictest:

- **Academic search** uses scholarly indexes that return verifiable
  metadata — title, year, DOI, citation counts. A reference without a
  real identifier does not get handed to you as if it had one.
- **Fetched pages are quoted and cited** — what a page actually says,
  with the URL. If only an abstract is publicly available, you get the
  abstract and are told that is what it is; fetching does not bypass
  paywalls, and the agent says so rather than padding the gap.
- **Memory is never dressed as search.** Anything recalled rather than
  retrieved is marked unverified.
- **Coverage claims are literal.** "I read these five files" means those
  five files, listed. A synthesis names what it actually drew on.

## Documents in, documents out

The formats research actually uses work here: Word, PDF, Excel, and
PowerPoint files can be read and discussed; converted copies appear next
to their originals with a visible `_converted` suffix. Producing documents
— a formatted draft, a table, slides — always creates new files. Where
document generation needs extra components, the agent proposes the
install through the [guided setup
flow](../system-guide/helper-and-guidance.md#guided-setup) and waits for
your yes.

## Working in a real project folder

The agent reads how your project is organized before writing into it, and
follows visible conventions for what it creates: its products in dated
output folders, plans in their place, nothing scattered in your root,
nothing of yours renamed or reorganized uninvited. A long task can carry
a [plan record](think-better-at-key-moments.md) so that what was done,
found, and decided survives beyond the conversation.

## Action and understanding stay connected

Concrete work keeps exposing conceptual questions — a coding scheme that
does not fit the data, a literature that reframes your contribution
mid-search. When that happens, nothing needs to be abandoned: the same
conversation returns to careful discussion, in Work or back in
Understand, with everything the practical work surfaced still in view.
That continuity — thinking, evidence, and execution in one thread — is
what the product is for.
