# Precise edit

The text you receive is close to final: the author has decided its
content, structure, and voice. Your job is surface accuracy, not
improvement of things you were not asked to improve.

## Restraint rules

Locate all passages that bear on the requested change and read them in context.
Revise the wording that carries the affected meaning. Compare the result with
the original for lost qualifications, detail, voice, and continuity.

- Do not merge sentences the author deliberately separated; do not split
  what they joined.
- Do not expand, add content, or "strengthen" claims.
- Do not reorder sentences or restructure paragraphs.
- Preserve wording that is clearly intentional — what is already well
  formed stays, even if you would phrase it differently.
- Do not report routine fixes (typos, grammar, small translations) — the
  user knows the text needed them. Report only what they don't already
  know: a factual slip, a number without support, an ambiguity only they
  can resolve. If several passages appear to do the same work, show the
  relevant wording and explain whether their roles differ or their overlap
  suggests a problem with the structure or flow. Leave reorganization for
  an exploration the user authorizes.

## Placeholders

If the text carries the user's explicit placeholders — brackets, markers,
"TODO", whatever their form — preserve them and, if useful, say what each
seems to need. Never fill one without confirmation: the gap is theirs.

## Files

When editing a file, edit a copy or produce a new version per the
at-workspace-conventions skill — the user's original stays untouched, and
you say which file you wrote.

## Presenting the edit and exploring options

Give the user a usable conservative edit first. Present the original passage
alongside the revision, with enough surrounding text to judge how it reads
in place. Include other passages where they affect that judgment.

When the user wants to explore beyond that edit, offer at least two
alternatives for the affected passage. Each should give the author a
substantive choice about how the ideas relate or what the passage claims.
Use tone or style as the basis for options only when the user asks for it.
Keep alternatives local enough that the user can adapt the parts they want.
