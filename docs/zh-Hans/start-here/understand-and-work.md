# 理解模式与工作模式（Understand / Work）

每条 Alt Theory 对话都运行在两种模式之一。区别不是「聊天对智能体」——两种模式都是智能体式的。区别在于：你向智能体开放了多少本机与工具生态。

## Understand（理解模式）

Understand 面向认真对话，并刻意收窄触达范围。

- 智能体在对话本身、你附加的文件、所选知识库，以及它自身知识上工作——并清楚标注来源性质。
- 它不浏览网页、不跑命令、也不在你的文件系统里四处走动。
- **Understand 中没有实时检索，这是设计如此。** 当某项主张需要核实时，智能体会说明这一点，并给出当前最佳理解，按扎实程度标注——既有知识、合理但未核实、或确实未知。它不会把记忆包装成「搜到的结果」。

Understand 是使用 Alt Theory 的完整方式，不是 Work 的阉割预览。若你主要用产品来思考、审视与讨论，可能大部分时间都在这里。

## Work（工作模式）

Work 保持同样的对话标准，并加上实践触达：

- **工作文件夹**（working folder，可选更多文件夹），智能体可在其中读写项目文件；
- **实时搜索与抓取**——通用网页、带可核验元数据的学术检索，以及整页抓取；
- **文档工作**——阅读 Word、PDF、Excel、PowerPoint，并生成新文档；
- **命令与安装**，始终经过可见的批准流程。

Work 不是「不再认真思考的生产力模式」。它把同一标准带进行动：有后果的选择会说明理由，保留出处，且**从不原地改写你的原文件**。

## 什么会请求许可

在 Work 模式下，有些事在你设定的边界内，有些事总会询问：

- 在你附加的工作文件夹内，智能体可逐步推进而无需每一步打断你。
- 读取这些文件夹之外、超出内置搜索工具的网络访问、以及安装任何东西——会弹出**批准请求（approval request）**，写明请求内容与你授予的权限。拒绝是安全的；对话会继续。

完整说明见 [权限、批准与智能体活动](../system-guide/permissions-approvals-agent-activity.md)。

## 切换模式

可随时在 Understand 与 Work 之间切换。切换从你下一条消息起生效。对话、推理、已附加材料，以及角色与知识库选择都会带过去——切换不会分叉或重置任何东西。

自然节奏往往是：在 Understand 里想清楚，直到下一步不再只是多聊几句，再切到 Work 去搜索、核实或产出，当动手暴露出概念问题时再回来。[使用 Alt Theory 应用](../README.md#using-the-alt-theory-app) 一节用真实研究场景展示这一节奏。

## 一句话怎么选

想只要思考、别的都不动时选 Understand；希望对话能碰到你的文件与实时外部世界时选 Work——答案变了就切换。
