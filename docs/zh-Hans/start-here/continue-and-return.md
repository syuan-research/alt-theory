# 继续、转向与之后再回来

真正的研究工作不是线性的：会暂停、分叉、回退，几周后再捡起。Alt Theory 的对话就是为此设计的。

## 对话是持久的

每条对话都保存在本地，出现在对话列表中，可按工作文件夹分组并搜索。首次交流后对话会自命名；随时可改名。重新打开任意对话即可继续——上下文、材料、模式与配置会一并恢复。

## 改方向，而不丢掉任何东西

你不只是「接着走」或「重来」：

- **Stop（停止）**——随时中断回复并转向。
- **编辑或改写**你较早的一条消息——对话从该点起用你的新表述继续。首次这样做时，应用会说明会重写什么。
- **Branch（分支）**——分出一条相关对话去试替代路径，原线保持完整。
- **BTW（旁白/旁线）**——打开携带当前上下文的小旁线对话，处理不该弄乱主线的题外话。若旁线后来变得重要，可提升为完整分支。

每种选项保留的东西不同；对照表见 [处理回复与对话控件](../system-guide/responses-and-controls.md)。

## 长对话仍能继续

长研究对话终会超过模型一次能看全的范围。临近时，应用会**压缩（compact）**对话：较早轮次被摘要，以便工作继续。这是可见的，不是静默的——有分隔标记边界，摘要可展开阅读。若某段关键内容绝不能因摘要丢失，请写入文件或计划记录；文件不会被压缩。细节见 [对话与历史](../system-guide/conversations-and-history.md)。

## 隔一段时间再回来

隔几天或几周重新打开对话时，恢复的是对话本身——历史、工作文件夹、知识库、模式。关于对话外的世界，有两点要诚实说明：

- 若期间工作文件夹被移动或改名，应用会告知并让你重新指定，而不是假装无事。
- 若文件自上次工作后有变化，智能体在真正动手前会先读当前文件——而不是迷信记忆里的旧版本。

这是产品的一贯姿态：回来应该成本很低，对话里关于项目的说法应与项目现状一致。
