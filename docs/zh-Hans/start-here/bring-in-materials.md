# 带入你的材料与上下文

研究对话总是「关于」某些东西——笔记、草稿、数据、论文。本页是把材料带进来所需的最少知识。

## 一屏说清各部分

- **对话（conversation）** 是你与智能体思考和做事的地方。它保留自己的历史与配置。
- **文件附件（file attachment）** 把某个具体文件放到智能体眼前——拖进输入区或用附加按钮。
- **工作文件夹（working folder）**（Work 模式）是本机上智能体可在其中工作的文件夹：读文件、创建新文件。附加文件夹是有意为之——它定义实践工作发生在哪里。
- **知识库（knowledge base）** 是策展过的参考材料——在相关领域启用后，智能体可查阅。

它们可自然组合：一条对话可能附加了你的草稿、以项目文件夹为工作文件夹，并启用某个知识库——也可以什么都没有。

## 智能体看见什么，以及如何核对

智能体看到你带进对话的内容——附件、工作文件夹内容、已启用的知识库——以及你写的文字。它看不到电脑上其余部分。若不确定当前附加或启用了什么，输入区会显示本对话的工作文件夹与知识库；你也可以直接问智能体——「你现在能看见什么？」是正常问题，答案会说明它实际读过哪些文件，而不是含糊保证。

## 真实文件，认真对待

Alt Theory 能读研究里真正会用到的格式——Word、PDF、Excel、PowerPoint——转换副本会与原件并排放置，文件名带 `_converted` 后缀，配对关系一目了然。

入门页也值得写明的一条约定：**原文件从不被原地修改。** 智能体修订文档时，会在副本上工作或生成命名清晰的新文件，并告诉你写到了哪个文件。文件始终是你的。
