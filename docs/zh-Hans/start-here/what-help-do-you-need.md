# 你需要哪类帮助？

基础已经有了。接下来去哪取决于你想做什么。

## 「想看看它能对我的研究做什么」

阅读 [使用 Alt Theory 应用](../README.md#using-the-alt-theory-app)——按工作类型组织的三页：

- [以理解为目标时](../using-the-app/when-understanding-is-the-goal.md) —
  探索、审视概念、建立理解。
- [在研究关键节点上想得更好](../using-the-app/think-better-at-key-moments.md) —
  设计、回复审稿、重构：重判断的时刻。
- [以具体动手为主任务时](../using-the-app/when-concrete-work-is-the-main-task.md) —
  产出、搜索、在文件中推进。

## 「想弄清或配置某个具体功能」

[系统指南](../README.md#system-guide) 对每个功能作权威说明：是什么、怎么用、如何核对当前状态，以及出问题时如何恢复。

## 「我已经在跑 agent harness」/「想集成或定制」

[进阶使用、集成与定制](../README.md#advanced-use-integration-and-customization)
覆盖插件、跨 harness 连续性、配置归属与优先级，以及修改产品本身的边界。

## 「出了问题」

- 功能相关问题：先看该功能的系统指南页——每页都有核对与恢复小节。
- 跨功能问题，或不确定归属：
  [故障排除](../help/troubleshooting.md)。
- 快速问答：[常见问题](../help/faq.md)。

## 在应用内提问

**Helper（帮助助手）** 是回答关于 Alt Theory 本身问题的内置助手——它从干净状态开始（不读取你当前对话），依据产品当前文档作答，包括用平实语言引导设置。可在 Toolbox 中找到。当它无法核实时，会如实说明并指向此处，而不是编造步骤——
[Helper 与应用内指引](../system-guide/helper-and-guidance.md)。

文档之外的事——缺陷、反馈、研究合作——见
[版本与进一步帮助](../help/releases-and-further-help.md)。
