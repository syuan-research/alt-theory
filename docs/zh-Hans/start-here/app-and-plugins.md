# 应用与插件

Alt Theory 产品不止一种形态。花一分钟弄清哪种适合你即可。

## 应用（App）

桌面应用是完整产品：对话界面、Understand/Work 能力模型、角色与知识库、内置技能、批准、导入与设置——一次安装，不依赖其他工具。面向并未日常泡在 AI 智能体 harness 里的人，也就是大多数研究者。

## 给已有 harness 的插件

若你已在某种 agent harness（Pi、Claude Code 等）中工作，未必想再开第二个应用。插件形态把 Alt Theory 的方法带进你已有的工具：

- **内置技能（bundled skills）** 不变——技能跨 harness 通用；
- 以你的 harness 自身格式提供的 **agent 定义**，承载 Alt Theory 的身份与原则；
- 可选：把 **知识库** 放在 harness 能读到的位置。

你得到的是 Alt Theory 的工作方式——有出处纪律的搜索、大动作前对齐、计划记录、克制编辑——在你自己的环境里。仍属应用独占的是产品表面：模式切换、批准界面、各类选择器与导入；这些由 harness 以自己的方式提供。

[插件与能力差异](../advanced/plugins-and-capability-differences.md) 记录各 harness 的确切差异，以及当前可用的打包形式。

## 应用建立在什么之上

应用的智能体引擎是 [Pi](https://pi.dev)，一个开放的 agent harness，生态活跃。即便你从不直接碰 Pi，了解这一点仍有用，因为由此带来若干好处：

- 对话以 Pi 兼容格式存储，工作不会被锁死在 Alt Theory 里；
- 技能遵循生态惯例，你安装的技能可两边用，Alt Theory 的技能也可在别处用；
- 其他 harness 的对话可以[导入](../system-guide/imports-and-continuity.md)并继续。

Alt Theory 补上通用 harness 没有的部分：以理解为先的行为、面向研究的资产，以及为学者而非软件工程师设计的界面。

## 怎么选

- 多数读者：用应用。不预设你已有任何东西，且功能齐全。
- 已有 harness、主要想要方法的人：用插件形态。
- 两者并用也完全合理——研究对话用应用，你已在工作的地方用插件。材料与技能可共享；见 [共享配置、技能、模型与资产](../advanced/shared-configuration-and-assets.md)。
