# 以具体动手为主任务时

有时下一步就是干活：查找并核实文献、读 PDF、转换幻灯片、起草章节、修订文档、在项目文件夹里推进。这是 Work 模式的主场——在你的材料上采取智能体行动，并保持与其他一切相同的诚实标准。（与本节其他页相同：这是目标，不是模式——不过这个目标通常需要 Work。）

## 讨论变成行动时会变什么

附加[工作文件夹](../system-guide/working-folders-files-paths.md)后，对话就有了行动场所。此后每一步与聊天工具的实践差异都可见：

- **你看见它在做什么。** 每个动作以一行出现在对话中——读了哪个文件、写了什么、跑了哪条命令、用了哪个技能——需要细节时可展开。
- **你看见改了什么。** 触及文件的一轮会以卡片命名这些文件，并统计增删；新文有预览，改文有前后对照，代码有 diff。
- **边界先问你。** 读取文件夹之外、访问网络、安装任何东西——都会弹出写明请求内容的批准请求。拒绝是安全的。
- **原件仍是你的。** 修订发生在副本或命名清晰的新文件上，智能体会告诉你写到了哪个文件。

## 像真的需要引用一样搜索与引用

文献工作中「编造的自信」伤害最大，因此纪律也最严：

- **学术搜索**使用返回可核验元数据的学术索引——标题、年份、DOI、被引次数。没有真实标识符的文献不会被当成有标识符的交给你。
- **抓取的页面会引用并标明出处**——页面实际说了什么，附上 URL。若公开只有摘要，你得到摘要并被告知就是摘要；抓取不会绕过付费墙，智能体会说明而不是用空话填洞。
- **记忆从不当作搜索。** 回忆而非检索到的内容一律标为未核实。
- **覆盖范围声明是字面意思。**「我读了这五个文件」就是那五个，并列出。综合会点名实际依据了什么。

## 文档进，文档出

研究真正用的格式在这里可用：Word、PDF、Excel、PowerPoint 可阅读与讨论；转换副本与原件并列，带可见的 `_converted` 后缀。产出文档——格式化草稿、表格、幻灯片——始终创建新文件。文档生成若需额外组件，智能体会通过[引导式设置流程](../system-guide/helper-and-guidance.md#guided-setup)提出安装并等你同意。

## 在真实项目文件夹中工作

智能体在写入前会先读懂项目如何组织，并遵循可见约定：产出放在带日期的输出文件夹、计划放在应有位置、不在你根目录乱撒、未经邀请不改名或重组你的东西。长任务可携带[计划记录](think-better-at-key-moments.md)，使已做、已发现、已决定的内容在对话之外仍可存活。

## 行动与理解保持相连

具体工作不断暴露概念问题——编码方案与数据不合、检索中途文献重新框定了你的贡献。这时不必放弃：同一条对话可回到认真讨论，留在 Work 或回到 Understand，实践工作暴露出的一切仍在视野中。这种连续性——思考、证据与执行在同一条线里——正是产品存在的理由。
