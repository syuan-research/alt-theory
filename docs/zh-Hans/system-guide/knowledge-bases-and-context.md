# 知识库与上下文

知识库是智能体在对话中可查阅的精选参考资料：预先选定并整理的领域资料，与任何单一项目的工作文件区分。

- 工作目录是你的项目：你正在处理的文件，附上后智能体可操作。
- 知识库是参考资料：智能体用以充当讨论事实基底的稳定材料。

一场对话可以同时有两者、其一，或都没有。

## 启用

输入框旁的知识库选择器为这场对话选择知识库。应用自带领域知识库（环境心理学核心是第一个），你可以添加自己的（[自定义](../advanced/customization-without-changing.md)）。选择无表示没有知识库可用，工作目录与附件不受影响。可以在对话中途切换知识库，从下一轮开始生效。

## 智能体如何使用知识库

启用知识库并不意味着每轮都查。智能体知道知识库可用及其覆盖范围，且在讨论需要事实基底时凭判断调阅，与决定读取项目文件的方式相同。

## 故障排查

- 回答忽略知识库：确认选择器上有选项而非无，并考虑问题是否真正触及知识库的领域。智能体不会强加无关材料。
- 对话中途切换知识库后感觉陈旧：变更从新的轮次起效，之前回答基于当时启用的知识库。重新提出真正重要的问题。
