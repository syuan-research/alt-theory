# 添加与管理技能

## 安装

没有应用市场。技能是包含可读文件的文件夹，把它放进应用查找的位置即可完成安装。

- 给所有工具使用（推荐）：`~/.agents/skills/<skill-id>/`（文件夹名即英文 id，例如 `my-lit-review`）。Alt Theory 与其他遵循同样约定的工具都会找到它。
- 放在项目内：工作目录里的 `.agents/skills/`（或 `.pi/skills/`）文件夹。技能在该文件夹被附上（工作模式）时生效，并随项目移动。

技能文件夹包含一份 `SKILL.md`，说明技能的用途与做法，以及可选的参考文件。这就是全部格式。技能是智能体遵循的指令，所以请安装你读过或信任的技能。

## 启用

设置中的技能菜单列出所有已发现的技能（内置、用户的、项目的），并控制各技能在何处加载。

- 启用按模式分别设置。理解模式与工作模式各有独立的启用集合。理解模式默认不加载外部技能，工作模式的默认集合更广。
- 修改立即生效。新对话使用新设置，已打开的对话在重开后采用。

## 优先级

技能优先级是全局设置三档：优先内置（默认）、优先用户、或冲突时询问。冲突指同一类别（两个检索类技能），不是任意两个技能。多个内置技能对同类用户技能让位（`doc-convert`、`page-fetch`、`web-search`）。细粒度规则见[共享配置与资产](../advanced/03-shared-configuration-and-assets.md)。

## 故障排查

- 一个技能始终未触发：在[命令面板](11-commands.md)中按英文 id 调用它（例如 `/my-skill`），然后检查它的 `SKILL.md` 描述。触发匹配的是该描述。目前没有中文别名。
- 错误的技能胜出：检查优先级设置，检查两者是否属于同一类别。不相关的技能会同时加载。
- 项目技能缺失：确认该文件夹已附上，且对话处于工作模式。
