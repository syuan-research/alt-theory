# 工作目录、文件与路径

工作目录是附在工作模式对话上的文件夹。智能体在此读取你的项目文件并创建新文件。

## 附上

在工作对话创建时选择一个工作目录，或之后追加。选择时使用系统常规的文件夹对话框。对话列表按工作目录分组，因此随着时间推移，列表会反映你的项目结构。

可以为同一对话追加更多目录，用于跨项目与源资料的工作。附上时，智能体获得该目录的访问权限，并读取该目录的自身约定（给智能体的笔记、项目结构），从而按该项目期望的方式工作。

没有工作目录时，工作对话仍有一个私人临时空间用于它创建的文件，但无法看到你的项目。

## 智能体在不同位置的权限

- 在附上的目录内：按工作需要读取、创建、编辑文件，无需逐步打扰。所有动作在对话中可见。
- 在附上的目录之外：读取未附上的文件或目录会触发[授权请求](13-permissions-approvals-agent-activity.md)，你看到路径后决定。对附上目录外执行写入不可用。工作目录是修改的硬边界。
- 在理解模式下：项目目录不会被附上。理解对话保留一个私人工作空间，智能体可在其中保存你要求的内容，但你的文件只能作为附件进入，超出该边界的读取需经授权。

## 智能体如何对待你的项目

约定属于[内置技能](09-bundled-skills.md)的一部分，且本身可读：

- 先读。智能体在写入前先读懂项目的组织方式，并遵循既有结构而非自己的默认。
- 原件不被触碰。修订文档意味着写入副本或一个命名清晰的新文件，绝不就地修改原件。
- 产出可查找。创建的内容放在合理位置：带日期的输出文件夹放产出物，`plans/` 放计划记录。不在项目根目录散落。
- 不擅自重组。智能体不会自行重命名、移动或重组你的文件。它提出建议，你决定。

## 文件面板与路径

右侧面板以文件树形式显示工作目录：浏览、打开文件查看，或在 Finder / 资源管理器中显示。文件可从面板加入讨论，面板也是工作完成后查看改动的地方。

当智能体提到文件时，倾向于显示相对于工作目录的路径。文档的转换副本以 `_converted` 后缀出现在原件旁边（[详情](07-documents-images-inputs.md)）。

## 故障排查

- 文件夹移动或重命名：重开时不会指向失效路径。应用会提示该目录缺失，让你重新选择或继续不使用。
- 看不到某个文件：检查文件在附上的目录内，对话处于工作模式，且文件是在智能体上次列出目录之后新创建（请智能体再列一次）。
- 智能体写入的文件找不到：那一轮的改动文件卡片与工具行列出了所有写入的文件与路径。从那里查起。
