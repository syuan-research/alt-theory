# 搜索、来源与网页内容

Alt Theory 中存在实时检索只有一个理由：让智能体关于世界的说法能对照世界来核对。本页说明有哪些检索、背后的出处纪律，以及没有检索时会发生什么。

## 有哪些检索（Work 模式）

- **学术搜索** — 直接查询学术索引（OpenAlex 与 Crossref），返回可核验元数据：标题、年份、DOI、被引次数与摘要。无需账户或密钥。这是文献工作的首选，因为带 DOI 的结果是你真能交给同事的文献。
- **通用网页搜索** — 其他一切：时事、软件文档、机构页面。同样无需密钥。
- **页面抓取** — 把特定页面取回为可读文本，以便带来源引用主张。两档：快速默认，以及面向反爬期刊站的更重浏览器档（首次需要时通过[引导式设置](helper-and-guidance.md)提供的单独、较大安装）。

Toolbox 的「在线查找」会调用这些；直接提问也可以。需要安装的搜索工具会通过批准流程提议一次。

## 出处规则

智能体交给你的每条事实陈述恰好属于三类之一，且必须保持区分：

- **此刻找到的** — 本对话中工具返回的。附带链接或 DOI。
- **模型记忆** — 回忆但未在此刻核实。标为未核实（引用尤其明确，例如「[Author, year?] — unverified」），或暂不给出。
- **推断** — 由其他事物推理得出。会用文字说清楚。

记忆从不当成搜索结果出场。这一条规则几乎就是产品文献工作可信的大部分原因。（关于规则本身的诚实说明：它通过产品指令与方法执行，在测试中表现良好——但没有任何系统能使编造不可能。若你发现未标注的主张，那是值得[报告](../help/releases-and-further-help.md)的缺陷，不是吹毛求疵。）

实践中你会注意到的两个推论：

- **样本量诚实。** 少数结果是有偏样本：一条摘要只支撑「有来源这样说」，绝不支撑「学界一致认为」。结果冲突时你看到的是分布，不是静默挑一个。
- **覆盖范围诚实。** 综合会点名实际读过哪些来源。「读完 40 个 PDF」就是 40，否则不说。

## 付费墙与访问限制

抓取不会绕过付费墙。若页面对公众只显示摘要，智能体就只得到摘要——并会说「仅摘要」并在其范围内工作，而不是填洞。期刊站的反爬墙常可用受保护抓取档通过；真正的付费墙不行，假装能过正是本产品要避免的那种编造。

## Understand 模式：无实时检索，诚实处理

Understand 按设计没有实时检索——收窄触达正是该模式的意义。对可核对事实，智能体默认是校准过的诚实：给出按扎实程度标注的当前最佳理解（既有 / 合理但未核实 / 未知），标出需要核实之处，绝不编造无法核对的引用。当核实成为任务时，把对话切到 Work——Understand 中 Toolbox 的查找入口会直接说明这一点，而不是显示禁用按钮。

## 核对

- 主张是找到的还是回忆的：会有标注；若偶有缺标，问——「这是此刻找到的还是来自记忆？」是正常问题，且要求诚实回答。
- 搜索实际做了什么：工具行显示每次查询与抓取。

## 恢复

- **搜索没什么用**：试另一条线（学术 vs 通用）、改写问题，或抓取已知可靠的起点页并顺其参考文献。模糊问题可先做廉价部分搜索——搜索与问题会彼此收紧。
- **抓取失败或返回挑战页**：诊断如此时智能体会升到受保护档；若该档未安装，会提议安装而不是静默失败。
- **需要的工具未安装**：引导式设置流程在对话中处理，需你确认。
