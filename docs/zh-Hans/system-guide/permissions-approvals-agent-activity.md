# 权限、批准与智能体活动

本页是 Alt Theory 信任模型的权威描述：智能体可以做什么、什么总是先问、你如何看到正在发生的事，以及你的选择意味着什么。

## 用平实语言说模型

你分层决定一条对话有多大触达：

1. **Understand 模式** — 无命令执行、无实时网络、无项目文件夹。对话、你的附件与所选知识库是全部表面。越界读取会弹出批准请求。
2. **Work 模式，在已附加文件夹内** — 智能体无需逐轮询问：读项目文件、写新文件、运行其技能描述的命令。这是你通过附加文件夹设定的边界；在边界内，顺畅推进是重点。
3. **Work 模式，在边界上** — 有些事无论触及哪个文件夹都会询问：
   - 读取你未附加的文件或文件夹；
   - 超出内置搜索与抓取工具的网络访问；
   - 安装任何东西；
   - 安全策略标记的操作（危险命令模式、逃出工作区的路径、可疑网络目标）。

## 批准请求

当某事越过边界时，对话暂停并显示：**操作**（究竟要尝试什么）与**范围**（说 yes 授予什么）。你的选项至少包括允许一次与拒绝；在底层策略支持时，会明确提供更广范围（本对话剩余时间）——从不默认假定。

两个值得信任的性质：

- **拒绝是安全的。** 智能体吸收拒绝并继续——另找路径，或坦率告诉你没有该访问时做不到什么。拒绝从不会损坏对话。
- **无答复等于否。** 若请求超时或对话关闭，结果视为拒绝。沉默从不成为同意。

## 诚实界定这是什么

这些是同意与护栏，不是物理隔离：策略层按规则检查操作，批准在边界把你纳入回路——与其他生产级智能体工具姿态相同。它不是操作系统沙箱，文档也不会那样称呼。两个后果：

- 保护为**监督诚实智能体做真实工作**而设计，不是为遏制主动恶意软件。
- 你安装的扩展与工具以你的用户权限运行——当作**受信任软件**：只安装你信任的、来自你信任的来源，就像任何程序。（技能是指令而非代码，但同样适用「只装你信任的」。）

## 看见智能体在做什么

可见性是持续的，不只在边界：

- **在对话中**：每个动作发生时都是
  [工具行](responses-and-controls.md)——读、写、命令、搜索、技能使用——可展开看细节。改动了文件的一轮以变更文件卡片结束。
- **跨对话**：对话列表标记每行实时状态——运行中、完成未读、失败，或**等待批准**——全局指示器显示多少对话在活动。若应用窗口在后台，完成、失败或阻塞在批准上会发系统通知，对话不会整个下午静默等你。

## 核对

- 智能体此刻在做什么？状态区显示当前阶段；工具行实时累积。
- 它实际改了什么？轮次结束卡片与文件面板的变更视图，按轮次与按文件。
- 什么在等我？列表状态与全局指示器。

## 恢复

- **拒绝了某事而工作卡住**：说明你更希望它怎么做——拒绝是转向，不是死胡同。若访问确实需要，附加文件夹或在再次请求时批准。
- **批准了后悔的事**：允许一次用过即消耗；对话范围的批准随对话结束。说清楚，智能体不会重复该操作。
- **动作中途被打断**（停止、崩溃）：已完成步骤记在转录中；没有部分隐藏。问「那到哪了？」并从诚实答案继续。
