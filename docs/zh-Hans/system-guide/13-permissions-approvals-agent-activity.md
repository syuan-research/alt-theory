# 权限、授权与智能体活动

智能体可做什么、什么始终需要询问、你如何看到正在发生的事。

## 模型，分层

1. 理解模式：不执行命令、不访问实时网络、不挂载项目文件夹。对话、附件与所选知识库是全部界面。超出此处的读取触发授权。
2. 工作模式，在附上的目录内：执行无需逐轮询问。读取、写入、运行技能描述的命令。
3. 工作模式，在边界处：以下始终需要询问。读取你的文件夹之外的内容，超出内置检索与抓取之外的联网，安装任何东西，策略标记的操作（文件系统破坏、权限提升、凭据路径访问、危险命令如 rm、curl、ssh、chmod，逃出工作空间的路径，可疑网络目的地）。

## 授权请求

对话暂停并展示该操作（正在尝试什么）与范围（允许意味着什么）。选项至少包含「允许一次」与「拒绝」，策略支持时提供更宽范围（本次会话允许，含 30 分钟窗口）。

- 拒绝：智能体另寻路径或说明无法做什么。对话继续。
- 无响应（超时或关闭对话）：视为拒绝。

## 这是什么

策略层按规则检查操作，授权流程让你参与边界。这是可信代码中的检查，不是操作系统沙箱。两个推论随之而来：

- 检查用于在智能体做真实工作时施加监督，不是用于隔离恶意软件。
- 你安装的扩展与工具以你的用户权限运行。策略约束操作，不能让不可信的扩展变得安全安装。安装你信任的，正如任何程序。

每次拦截与授权都追加到会话级安全审计日志。

## 查看智能体在做什么

- 在对话中：每个动作以一条[工具行](05-responses-and-controls.md)实时出现。改动文件的轮次以改动文件卡片收尾。
- 跨对话：列表上每行的状态标记（运行中、已完成未读、失败、等待授权）。当窗口位于后台时，完成、失败或被授权打断的运行会触发系统通知。

## 故障排查

- 被拒绝后停滞：说明你想让它做什么。附上该文件夹，或在重新请求时授权。
- 授权了后悔的内容：「允许一次」用完即失效，会话范围会过期。
- 中途被打断：已完成的步骤在转录中。
