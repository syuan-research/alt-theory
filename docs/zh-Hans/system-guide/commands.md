# 命令

在输入区键入 `/` 会打开**命令面板（command palette）**——可按名称调用的完整列表，边输入边自说明。

## 里面有什么

- **每个已激活技能**，可调用为 `/skill-name`——立刻应用特定方法的可靠方式，内置或你自己的。
- **对话命令**：
  - `/branch` — 从这里分支本对话；
  - `/btw` — 打开携带当前上下文的旁线对话；
  - `/new` — 开始新对话；
  - `/compact` — 立刻压缩本对话，在你选择的暂歇点，而不是被上限逼迫时。

面板随输入过滤，每条显示做什么——它会教自己，因此 Toolbox 的「所有技能…」入口只是把你丢到这里。

## 命令 vs 句子

面板里的没有一项是唯一做法。「我们在这里分支吧」「开始前先和我对齐」「总结这段对话」作为普通句子也有效——面板存在是为了精确（就是这个技能）、速度，以及发现可用之物。用哪个适合当下就用哪个；智能体把显式命令当指令，不当建议。
