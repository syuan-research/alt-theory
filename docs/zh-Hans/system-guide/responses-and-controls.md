# 处理回复与对话控件

本页是阅读智能体向你展示的内容、以及引导对话的权威说明。

## 阅读回复

回复可以不只是文字：

- **Thinking（思考）** — 模型作答前的推理，以可折叠块显示。读它是可选的；存在是因为*如何*得出结论往往与结论同样有用。
- **工具行（tool lines）** — 每个智能体动作一行轻量记录，按类型表述：读文件、写文件（带文件名）、编辑文件、跑命令（命令本身在行上）、搜索，或使用具名技能。点击可展开发生了什么：新文有短预览，改文有前后对照，代码有 diff，命令有输出。
- **渲染内容** — markdown 表格渲染为表格；mermaid 图示渲染为图。
- **轮次结束的变更文件卡片** — 当一轮改动了文件，卡片列出它们并显示增删。点进文件面板看完整细节。（导入的对话在导入轮次没有动作日志，因此不显示卡片——应用不会伪造一张。）

## 上下文环

输入区旁有一个小环，显示本对话已用模型上下文窗口的多少。工具提示分解输入/输出 token、缓存使用，以及提供商回报的费用。环接近满时，[压缩](conversations-and-history.md) 是对话继续的方式。

## 引导控件

- **Stop（停止）** — 中途中断智能体。随时安全；已做的会记下来，你从那里引导。
- **Copy（复制）** — 任意消息，你的或智能体的。
- **Edit / revise（编辑 / 改写）** — 改你较早的一条消息；对话从该点起用新表述继续，之后轮次离开活动线（[细节](conversations-and-history.md)）。
- **Branch（分支）** — 从任意消息开始相关对话。分支携带到该点为止的一切；原线不受影响。
- **BTW** — 右侧小栏中的旁线对话，携带当前上下文，处理不该弄乱主线的题外话。长大了的 BTW 可**提升为分支**。
- **Helper** — 也在对话旁，但*从干净状态开始*，看不到你的讨论；用于关于应用本身的问题（[细节](helper-and-guidance.md)）。在你选择二者时，应用会说明这一区别。

## 我想用哪个？

| 你想… | 使用 | 保留什么 |
|---|---|---|
| 修正带偏讨论的框架 | 改写 | 到改写消息为止的历史 |
| 对已完成对话试不同续写 | 复制（从列表） | 完整历史的独立副本 |
| 认真对待替代路径 | 分支 | 到分支点为止的一切，新线 |
| 问题外问题 | BTW | 完整当前上下文，侧栏 |
| 问应用怎么用 | Helper | 不带入任何东西——设计上干净上下文 |
| 开真正新话题 | 新对话 | 什么都没有——干净起点 |

## 恢复

- **停了回复又后悔**：直接请智能体继续——什么都没丢。
- **改写了错误的消息**：移除的轮次已从活动线消失；若重要，下次先从改写前分支。拿不准时先分支，再改写。
- **表格或图示渲染不对**：源文本完好——可复制出去；渲染问题是外观问题，值得
  [报告](../help/releases-and-further-help.md)。
