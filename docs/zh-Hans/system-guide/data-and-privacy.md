# 你的数据、隐私与离开本机的内容

对研究用户而言，这不是偏好页——这是合规问题。敏感访谈、学生记录、受使用协议约束的数据、审稿中的禁运稿：能否使用某工具，取决于能否可辩护地说清数据去哪。本页就是该答案，精确陈述。

## 你的数据在哪里

应用产生的一切都**本地、在这台电脑上**，在一个应用数据目录中：对话及其历史、记录与配置、对话工作区中创建的文件。没有 Alt Theory 云、没有账户服务器、没有遥测管道、没有同步。应用不「打电话回家」。

你自己的项目文件留在原处——附加工作文件夹授予访问权；不会把项目复制或上传到任何地方。

## 究竟什么会离开本机

本地优先**不等于**什么都不离开。存在三股流动，均由你的使用发起：

1. **到你的模型提供商。** 这是必须理解的关键一项：模型响应的一切会发往你配置的提供商——你的消息，以及智能体为工作而读取的文件内容。若智能体读你的访谈转录以回答相关问题，该转录文本就去了提供商，在你的账户与提供商数据条款下。「文件留在本地」对存储成立，对模型看见的内容不成立。敏感工作请据此选择提供商——这与选择把草稿发到哪封邮件是同类判断。
2. **实时检索（Work 模式）。** 搜索发往搜索服务，抓取发往被抓取的站点。查询文本对这些服务可见，就像你在浏览器中做的任何搜索。
3. **没有别的。** 无使用分析、无内容分享、无你在对话工具行中看到智能体使用之外的第三方服务。

(1) 的实践后果：对你不得发给任何第三方的材料，真正要紧的边界是模型提供商。自托管提供商，或条款被你协议允许的提供商，会改变答案；应用本身不增加额外暴露。

## 删除与保留

- 应用对本地对话**无自动保留或过期**——在你删除前它们是你的。
- **删除对话**把它从应用目录移除。对话数据是应用数据目录中的普通本地文件——可审计、可移除；别处不持有。
- **提供商**对已发送内容的保留受其条款约束，不受应用约束——与任何 API 使用相同。

**备份与换机**直接得出：数据目录*就是*应用状态。复制即完整备份；放到新机器上应用会接管。无需导出仪式，无需账户迁移。

## 对伦理委员会怎么说

一段话版本，按字面准确：*该应用将所有对话与工作数据存储在研究者本机本地，除向研究者配置的 AI 模型提供商传输外不外传——提供商接收对话内容以及助手被要求阅读的文件内容——且在使用实时搜索时，将查询文本发往所查询的服务。不涉及第三方分析或存储服务。*
