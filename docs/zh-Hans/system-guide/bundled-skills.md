# 内置技能

内置技能是写下来的 Alt Theory 方法。每个都是可检查的可读文件；合起来覆盖产品如何查找、如何处理文本与文档、如何运行协作本身，以及如何帮助使用应用。下方每条说明技能为你做什么、使用中如何显现、适用于何处。

你自己的技能可优先于其中任意一个——见
[添加与管理技能](add-and-manage-skills.md)。

## 查找

### search-policy

每次搜索背后的纪律：何时值得实时检索、三方出处规则（此刻找到 / 记忆 / 推断）、对薄弱结果的诚实处理，以及无法核实时的校准回退。你在每条回答的主张与引用标注中看到它。两种模式都适用——在 Understand 中约束无检索时的诚实。

### web-search *(Work)*

实时通用与学术搜索。学术查询走返回 DOI、年份与被引次数的学术索引；通用查询走无需密钥的网页搜索。体现为搜索工具行与你可真正核验的文献。首次使用可能提议安装小工具。

### page-fetch *(Work)*

把 URL 取回为可读文本，以便带来源引用。两档：快速默认；面向反爬期刊站的更重浏览器档（较大安装，首次需要时提供）。不绕过付费墙，并会说明。

## 处理文档与文本

### doc-convert *(Work)*

转换文档（docx、pptx、xlsx、pdf → markdown）供阅读，并按请求生成新文档文件。转换副本与原件并列，带 `_converted`；从不碰你的原件。

### precise-edit

面向接近定稿文本的克制编辑：语言准确而不重构，保留你的有意选择，从不擅自填占位符，选项是真正不同的替代而不是近义词替换。你交出大体完成的文稿时就会显现。

### workspace-conventions

智能体创建文件放哪、如何命名：先读项目自身结构，带日期输出文件夹，计划进 `plans/`，原件不动，不擅自重组。你看到的是：几周智能体工作后工作文件夹仍可理解。

## 运行协作

### adaptive-aligning

方向设定工作的对齐访谈：分批提问，每题携带智能体自己的最佳猜测，让你看清双方差多远；高置信点变成确认而非问题。在你要求对齐时触发（多种措辞与语言），或在凭猜测行动成本过高时触发。

### adaptive-plan-record

跨越多步、超出单条对话的工作用的活计划文档：目标优先，阶段松散持有，每次行动揭示了什么，已决定 vs 假设 vs 仍开放。住在工作文件夹中，因此能在对话压缩后存活，并干净交接给后续对话或合作者。

### conversation-summary

把当前对话变成保存的 markdown 摘要或交接说明——保留出处（你确认了什么、共同发展了什么、什么是智能体推断），开放问题保持开放，不偷偷变成结论。

### imported-session-context

约束[从其他 harness 导入](imports-and-continuity.md)的对话：优先连续性而非猜疑——读当前文件而不是对历史含糊其辞，从不编造导入未携带的内容，从导入自身记录回答「丢了什么」。

## 应用本身

### alt-theory-help

Helper 自身的技能：依据当前文档回答关于 Alt Theory 的问题，使用可见运行时状态，并说明未能核实什么，而不是编造步骤。

### setup-helper *(Work)*

平实语言的环境设置：安装技能所需、提供商与密钥配置指引、可选浏览器档。你体验到的规则就是它的规则——请求前先解释、从不静默安装、事后核实、诚实报告。

### model-image-support

检查特定模型能否读图（对照提供商当前文档，不凭名称猜测），并把答案记入模型配置，使图像附件可用。
