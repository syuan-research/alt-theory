# Alt Theory 文档

Alt Theory 是面向社会科学的研究工作区。它把认真、诚实的 AI 对话，与在需要时对你的材料采取行动的能力放在同一条会话里。

本套文档覆盖 Alt Theory 应用当前发布线。Alt Theory 处于活跃 alpha 开发中；此处描述反映已文档化的版本行为，已知限制会列出而不是隐藏。
