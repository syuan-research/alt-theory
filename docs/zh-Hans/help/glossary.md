# 术语表

产品用语，定义一次。交叉引用指向各权威页。

**Understand（理解模式）** — 认真对话、触达收窄的能力模式：无命令执行、无实时网络、无项目文件夹。使用产品的完整方式，不是 Work 的预览。
[→ 理解模式与工作模式](../start-here/understand-and-work.md)

**Work（工作模式）** — 具有实践触达的能力模式：工作文件夹、实时搜索与抓取、文档产出、命令——在可见批准之下。
[→ 理解模式与工作模式](../start-here/understand-and-work.md)

**Conversation（对话）** — 使用 Alt Theory 的基本单位：一条讨论与行动的线程，自有历史、模式、模型与材料。持久、可恢复、可移植。
[→ 对话与历史](../system-guide/conversations-and-history.md)

**Branch（分支）** — 从某条消息分出的相关对话，携带到该点为止的一切，原线完整。
[→ 处理回复与对话控件](../system-guide/responses-and-controls.md)

**BTW** — 主对话旁侧栏中的旁线对话，携带当前上下文；用于题外话。可提升为分支。
[→ 处理回复与对话控件](../system-guide/responses-and-controls.md)

**Helper（帮助助手）** — 回答关于 Alt Theory 本身问题的内置助手。从干净状态开始（不读你的对话），依据当前文档作答。
[→ Helper 与应用内指引](../system-guide/helper-and-guidance.md)

**Working folder（工作文件夹）** — 附加到 Work 对话的本机文件夹；智能体可读与创建文件的场所，也是它可修改范围的边界。
[→ 工作文件夹、文件与路径](../system-guide/working-folders-files-paths.md)

**Knowledge base（知识库，KB）** — 策展参考材料，按对话可选，智能体可查阅以奠基讨论。
有别于工作文件夹。
[→ 知识库与上下文](../system-guide/knowledge-bases-and-context.md)

**Role（角色）** — 可选呈现层：语气、节奏、教学风格。改变智能体听起来如何，从不改变原则。
[→ 定制](../advanced/customization-without-changing.md)

**Soul** — 身份层：智能体的世界观与原则，任何角色都不可覆盖。可读文件，与其他一切一样。
[→ 定制](../advanced/customization-without-changing.md)

**Skill（技能）** — 塑造智能体如何处理某类任务的可读指令文件。内置技能承载产品方法；你自己的以平等身份参与。
[→ 技能如何工作](../system-guide/how-skills-work.md)

**Command（命令）** — 可从 `/` 面板按名称调用的任何东西：技能，以及 /branch、/compact 等对话操作。
[→ 命令](../system-guide/commands.md)

**Toolbox（工具箱）** — 输入区旁重点动作的短菜单；是前门，不是完整清单。
[→ Toolbox](../system-guide/toolbox.md)

**Approval（批准）** — 动作越过对话边界时显示的请求（域外读取、网络、安装）。拒绝始终安全；沉默等于否。
[→ 权限](../system-guide/permissions-approvals-agent-activity.md)

**Compaction（压缩）** — 把长对话较早轮次可见地浓缩为摘要，使对话能在模型上下文窗口内继续。
[→ 对话与历史](../system-guide/conversations-and-history.md)

**Import（导入）** — 把另一 harness（Claude Code、Codex、OpenCode、Grok Build）的对话带入 Alt Theory，成为普通、可继续的对话——忠实，损失标注而非遮掩。
[→ 导入与连续性](../system-guide/imports-and-continuity.md)

**Plugin（插件）** — 为在其他 harness 内使用而打包的 Alt Theory 资产：内置技能不变，加上以该 harness 格式承载产品身份的 agent 定义。
[→ 插件与能力差异](../advanced/plugins-and-capability-differences.md)

**Pi** — 应用所基于的开放 agent harness。对话、技能与配置遵循生态约定而非专有约定的原因。
[→ 应用与插件](../start-here/app-and-plugins.md)

**Model / provider（模型 / 提供商）** — 驱动对话的 AI 模型，以及在你账户下供应它的服务。应用与模型无关；你按对话选择。
[→ 模型、提供商与访问](../system-guide/models-providers-access.md)

**Provenance（出处）** — 按来源标注每条主张的纪律：此刻找到的（带引用）、模型记忆（标未核实），或推断（说明如此）。产品的中心诚实规则。
[→ 搜索、来源与网页内容](../system-guide/search-sources-web.md)
