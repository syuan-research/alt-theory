# 故障排除

跨功能问题，或不明显属于某一功能的问题。功能局部问题请先看各系统指南页的核对与恢复小节——知道涉及哪个功能时那是更快的路径。

## 完全无法开始对话

几乎总是提供商链路。按
[模型、提供商与访问](../system-guide/models-providers-access.md#recovery-i-configured-it-but-it-doesnt-work)
中的清单走：提供商已保存*且*激活 → 密钥有效且有余额 → 模型 id 仍有效 →
重新打开。应用按设计在没有有效提供商时拒绝开始对话——修复在「设置 → 模型」，不在反复重试。

## 智能体似乎卡住了

先区分状态——看起来相似，应对不同：

- **在等你的批准**：有待处理批准请求——检查对话与列表中的等待批准标记。回答它；在你回答前什么都不会继续。
- **在做长工作**（大读取、慢抓取）：状态区显示活动，工具行持续出现。稍等，或**停止**并改向——停止始终安全。
- **真正卡住**（状态不动、无待批准）：停掉它，然后继续对话。若对话在同一操作上反复卡住，那是值得报告的模式。

## 搜索、抓取或读文档一直失败

- 单个页面或站点失败 → 多半是该站点（墙、反爬）：提供时试受保护抓取档，或换来源。
- 全部失败 → 工具本身：装了吗？（引导式设置流程可按请求重新核实——请智能体检查搜索工具。）网络是否过滤目标？
- 文档失败 → 见
  [文档、图像与其他输入](../system-guide/documents-images-inputs.md#recovery)：
  受保护/损坏/扫描文件各有具体答案。

## 重新打开后对话看起来不对

缺尾、渲染异常、意外模型：刷新一次，再查可见通知——过时工作文件夹、模型回退、资产回退——各自点名发生了什么、该做什么
（[参考](../advanced/compatibility-updates-debugging.md)）。带占位块的导入对话是在向你展示诚实标注，不是损坏
（[占位符含义](../system-guide/imports-and-continuity.md)）。

## 安装中途失败

设置流程会报告成功与失败了什么——没有假装。重跑（请智能体重试安装）；底层安装器可安全重复。若机器需要代理或阻止下载，那是常见原因，失败信息中的手动替代是变通办法。

## 是配置问题、提供商限制，还是缺陷？

最省时间的分流：

1. **新对话、默认设置** — 能复现吗？不能：配置问题；对照可工作的默认
   （[诊断顺序](../advanced/compatibility-updates-debugging.md#debugging-an-integration)）。
2. **同一提示、不同模型/提供商** — 是否跟着提供商走？若是：提供商限制（速率、上下文大小、能力）；修复在提供商侧或换模型。
3. **默认设置下跨提供商仍复现** — 多半是真缺陷。
   报告时写：做了什么、发生了什么、期望什么、应用版本、平台，以及对话是否导入或压缩过。
   [在哪里报告](releases-and-further-help.md)。

## 答案是「应用还做不到」时

在调试「其实是边界、不是故障」的东西之前，先看
[已知限制](compatibility-formats-limitations.md)——扫描 PDF、修订痕迹输出、云文档等列在那里并附诚实状态。
