# 常见问题

跨页或触及产品边界的问题。功能问题会指向权威页，而不是在此重复作答。

## 关于使用

**它能帮我写论文吗？**
它可以与你一起起草、修订、重构文本，并在过程中对来源诚实。它不会交给你一份藏起思考的抛光成品——按设计它会暴露缺口、替代路径与不确定性，留给你判断。若你想要的是每条提示最大化「听起来已完成」输出的工具，本产品刻意不是那种。你得到的是可辩护的工作。

**为什么它不直接给我答案？**
问题真正已有定论时，它会直白回答。当它放慢——区分概念、问什么证据会改变你的主张、给出选项——那是产品在工作：对研究问题，过早的自信答案通常是错的。若你希望它表态，直说；它会表态，同时告诉你该表态立在什么之上。

**使用需要懂技术吗？**
不需要。应用一次安装，设置用平实语言引导
（[Helper](../system-guide/helper-and-guidance.md)），不预设终端经验。唯一可辨认的技术步骤——从模型提供商拿到 API 密钥——会逐步引导。

**该用哪个模型？**
应用与模型无关；质量跟随模型，因此判断重的工作用预算允许的最强模型。产品的方法（出处标注、诚实的不确定性）跨模型成立——由产品自身指令强制，不靠模型档位。可配置多个并[按对话切换](../system-guide/models-providers-access.md)——例行工作用便宜模型、关键节点用强模型，是合理模式。

**要花多少钱？**
软件免费开源。你向模型提供商按用量付费，按其定价——应用不加价，并
[边用边显示用量与费用](../system-guide/responses-and-controls.md#the-context-ring)。

## 关于信任

**它会编造引用吗？**
构建目标是不这样做：文献来自带 DOI 的实时学术搜索，或明确标为未核实；记忆从不当成搜索结果；「我无法核实」是正常回答。见
[搜索、来源与网页内容](../system-guide/search-sources-web.md)。
没有任何系统能使编造不可能——但在这里它违反产品明示规则，而不是流畅度可接受的代价。

**我的数据隐私吗？** / **敏感材料能用吗？**
一切本地存储；离开本机的恰好是发往你配置的模型提供商的内容，以及 Work 模式下的搜索流量。精确答案——包括可给伦理委员会的一段话——见
[你的数据与隐私](../system-guide/data-and-privacy.md)。

**AI 行为真的与其他工具不同吗？**
身份、原则与方法是仓库中的可读文件——soul、角色、技能——不是营销口号。读它们，再拿难案例检验；产品由想知道失败何时发生的人构建。

## 关于产品

**与 ChatGPT / 通用助手有何不同？**
三个结构差异：为研究判断而非讨好式回答构建的行为；你控制的 Understand/Work 边界而非一刀切的智能体访问；本地优先存储与可读、可移植格式。更完整的回答见
[Alt Theory 是什么](../start-here/what-alt-theory-is.md)。

**与 Claude Code / Pi / 编码 harness 有何不同？**
共享生态（并可[从它们导入](../system-guide/imports-and-continuity.md)），但为不同工作构建：以理解为先的研究工作，把 harness 机制包进面向学者的界面与行为模型。若你已住在 harness 里，诚实建议可能是
[插件形态](../advanced/plugins-and-capability-differences.md) 而不是应用。

**能用其他语言吗？**
对话：可以——智能体用你的语言回答。界面目前为英语；简体与繁体中文已在计划中。文档以英语为先。

**提到研究——我被研究了吗？**
没有。公共应用无遥测，不向项目发送任何东西
（[隐私](../system-guide/data-and-privacy.md)）。Alt Theory 也是关于学者 AI 支持的研究计划，与公共应用分开的是有明示同意的研究情境部署。若你有兴趣贡献：
[版本与进一步帮助](releases-and-further-help.md)。

**X 何时支持？**
[已知限制](compatibility-formats-limitations.md) 诚实列出当前边界；变更日志与发布显示什么在动。
alpha 意味着列表以真实节奏变化。
