# 兼容性、格式与已知限制

参考表，保持诚实。列为限制的是当前边界，便于你据此规划——不是何时会变的承诺。

## 平台

| 平台 | 状态 |
|---|---|
| macOS（Apple Silicon） | 支持（打包应用与源码构建） |
| Windows（x86） | 支持（打包应用与源码构建） |
| 其他组合（Intel Mac、Windows ARM、Linux） | 未测试、不作承诺；源码构建可能可用但未核实 |

## 界面语言

| 语言 | 状态 |
|---|---|
| 英语 | 当前 |
| 中文（简体与繁体） | 计划中 |

对话语言依赖模型，实际上不受限——智能体用你使用的语言回答。

## 文件格式

| 格式 | 读 | 产出 |
|---|---|---|
| Markdown / 纯文本 | 是 | 是 |
| Word (.docx) | 是 | 是（作为新文件；需一次性组件安装） |
| PDF | 文本抽取（无 OCR——扫描/仅图像 PDF 抽不出） | 否 |
| Excel (.xlsx) | 是 | 是（作为新文件；组件安装） |
| PowerPoint (.pptx) | 是（按幻灯片文本） | 是（作为新文件；组件安装） |
| 图像（PNG、JPEG、GIF、WebP） | 在支持图像的模型上 | 对话中 mermaid 图示 |

## 导入来源

| 来源 | 状态 |
|---|---|
| Claude Code | 支持 |
| Codex | 支持（加密推理/摘要保持不重放，已标注） |
| OpenCode | 支持 |
| Grok Build | 支持 |
| Pi | 原生格式——直接可续写，而非经导入对话框 |
| 其他工具 | 不支持；从源工具导出 markdown 是手动路径 |

导入仅限本地（源工具数据须在本机），对源只读。边界细节：
[导入](../system-guide/imports-and-continuity.md)。

## 提供商访问

API 密钥适用于任何已配置的兼容提供商。订阅登录对支持的提供商可用（目前 OpenRouter、xAI、OpenAI Codex、Anthropic）。兼容 API 的本地模型服务器可配置为提供商。

## 已知限制

- **无 Word 修订痕迹输出。** 修订你的 .docx 会生成编辑副本加通俗变更摘要——不是 Word 修订标记。
- **无 OCR。** 纯扫描/仅图像 PDF 没有可抽取文本。
- **无云文档集成。** Google Docs、Overleaf 等除手动导出/导入文件外不可达。
- **Understand 模式无实时检索** — 设计如此，代之以诚实标注（[原因](../system-guide/search-sources-web.md)）。
- **不绕过付费墙。** 付费源你得到的是公开摘要。
- **无文献管理器集成。** 文档中的 Zotero/EndNote 域代码在你原件中原样保留（原件从不被编辑），但应用不读写文献管理器数据。
- **一个窗口焦点一条对话** — 并行 Work 对话会运行并信号状态，但只有一个活动视图；重型多智能体编排不是本产品。
- **alpha 仍在动。** 界面与内置资产发布间仍可能变化；[策略](../advanced/compatibility-updates-debugging.md)
  精确说明什么受保护、什么不受。
