# 外挂与能力差异

面向在应用与外挂形态之间选择，或同时使用两者的读者。

## 外挂形态

外挂是 Alt Theory 的资产按所用工具的标准转换而来，并非应用的移植。

- 内置技能保持原样，即与应用发布的是同一份方法文件（[目录](../system-guide/09-bundled-skills.md)）。
- 按所用工具自有格式编写的智能体定义，承载 Alt Theory 的身份与原则。
- 可选地，一份放在所用工具可读取位置的知识库。

## 能力差异

| 能力 | 应用 | 外挂于用户工具 |
|---|---|---|
| 理解优先行为（原则） | 内建 | 通过智能体定义 |
| 内置方法技能 | 内建 | 同一份技能，安装到工具 |
| 理解/工作模式边界 | 由应用强制 | 由工具的权限模型控制 |
| 授权界面与策略层 | 应用的 | 工具的 |
| 检索/抓取/转换工具 | 内置 CLI 工具通过技能调用 | 工具的原生工具，或同一份 CLI |
| 知识库选择器、角色界面 | 应用界面 | 手动 |
| 对话列表、分叉/顺带/助手界面 | 应用界面 | 工具的 |
| 智能体团队与子代理会话 | 应用功能 | 工具的委派 |
| 来自其他工具的导入 | 应用功能 | 不包含 |

方法技能（`search-policy`、`adaptive-aligning`、`adaptive-planning`、`precise-edit`、`workspace-conventions`）以纯指令形式迁移。三个工具驱动的技能（`web-search`、`page-fetch`、`doc-convert`）指定具体 CLI 工具，这些必须安装在宿主上，或替换为所用工具的原生工具。`search-policy` 两种方式都可移植，它指明所需工具的类型。

## 不能迁移的内容

所用工具的权限模型取代理解/工作模式。如果所用工具默认开放广义工具访问，外挂只带来 Alt Theory 的判断力，不带来应用的强制机制。请将所用工具的权限调整到与之匹配。

## 选择

- 需要方法，且工作已在工具中，外挂。
- 需要强制的环境、研究界面与 UI，应用。
- 两者都想要，受支持。共享位置存放的技能同时服务两者，对话可在[两者间移动](02-cross-harness-work.md)。

## 可用性

外挂包装跟随应用的发布线，各工具的当前安装说明见仓库。(planned)
