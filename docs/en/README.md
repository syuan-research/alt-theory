# Alt Theory Documentation

## Provenance and status

This documentation set was generated by an AI agent from product code,
development process docs, and notes, then human-reviewed. Human review is
still in progress. Features marked `(planned)` and the code they describe
are still evolving. **Errors are possible.** Prefer the running app and
the repository code when they disagree with these pages.

The Simplified Chinese counterpart is in `docs/zh-Hans/`. Some pages may lead
the English edition after manual review; both public sets ship with the app.

Invocable names (skill ids, slash commands) stay exact English identifiers.

---

Alt Theory is a research workspace for the social sciences. It pairs
careful dialogue with the ability to act on your materials, in the same
conversation. Its central behavior is treating uncertainty (about
direction, sources, memory, communication) as the work to do, not a
weakness to smooth over.

The app is in active alpha. Interfaces and configuration may change
between releases; current limits are listed on
[Known Limitations](help/compatibility-formats-limitations.md).

## Releases, bug reports, and the research program

Versions carry their maturity in the name: an `-alpha` tag means active
development, usable and in real research use, while still moving. The
repository changelog records what each release changed in plain terms.
What alpha means for compatibility (what is protected, what may change)
is in [the compatibility
policy](advanced/compatibility-updates-debugging.md).

Getting help, in order of closeness:

1. The in-app [Helper](system-guide/helper-and-guidance.md), for how-do-I
   and where-is questions, guided setup, and plain-language explanation.
   It answers from current documentation and says what it cannot verify.
2. These docs: canonical feature pages
   ([System Guide](#system-guide)), problem-shaped help
   ([Common Questions](help/common-questions.md)), boundaries
   ([Known Limitations](help/compatibility-formats-limitations.md)).
3. The repository: `github.com/syuan-research/alt-theory` for source,
   changelog, and the issue tracker.

A useful bug report includes what you did, what happened, what you
expected instead, the app version and platform, and whether the
conversation involved was imported or had compacted. The
[triage steps](help/common-questions.md#configuration-problem-provider-limitation-or-bug)
help file it as the right kind of problem. An unlabelled claim, an
invented reference, or a silent substitution is always a bug here.

Alt Theory is also a long-term research effort: what kind of AI support
scholars actually need, and how to know. The current product embodies
provisional answers; disagreement is useful data. For hard cases where
it failed, research collaboration, or participation in studies, contact
the project through the repository.
