# When Understanding Is the Goal

Understanding is a goal, not a mode. It usually lives in Understand mode,
but when it needs live search it moves to Work.

## Alignment before the work

For direction-setting work, the agent aligns with you first rather than
acting on guesses. Adaptive aligning sends batched questions, each
carrying the agent's own best guess, so the gap between your framing and
its reading becomes explicit. See
[Think Better at Key Moments](think-better-at-key-moments.md).

## Options over conclusions

Unless you or the context ask for a commitment, the agent returns the
uncertainty space: what is determinate, what the options are, and what
each commits you to. A layered-why layer explains why in relation to
your high- and mid-level needs and on a problem keeps offering options.
(planned)

## Verification

In Understand mode there is no live lookup, so recalled information is
marked unverified. When verification is the next step, switch to Work
for academic search with DOI-verified references. See
[Search, Sources, and Web Content](../system-guide/search-sources-web.md).

## Preserving a long discussion

Ask for a conversation summary at a resting point, or save key state to a
file. See [Bundled Skills](../system-guide/bundled-skills.md).
