# When Things Are Uncertain

The features that address the kinds of uncertainty you actually run into.
Each is one line here and a canonical page in the system guide.

- **Misalignment with the agent.** A clarification reset opens a short
  re-alignment stretch. (planned)

- **Uncertain direction.** Adaptive aligning interviews you before
  direction-setting work: batched questions with the agent's best guesses.
  See [Think Better at Key Moments](think-better-at-key-moments.md).

- **Incomplete understanding.** By default the agent returns the
  uncertainty space (what is determinate, what the options are), not a
  verdict. A layered-why layer explains why in relation to your needs.
  (planned) See [When Understanding Is the
  Goal](when-understanding-is-the-goal.md).

- **Unverified claims.** Every claim is labelled found now (cited),
  recalled from memory (marked unverified), or inferred. See
  [Search, Sources, and Web Content](../system-guide/search-sources-web.md).

- **Context too long to hold.** Compaction condenses earlier turns into a
  summary the agent carries forward, marked by a visible divider. See
  [Conversations and History](../system-guide/conversations-and-history.md).

- **Returning to old work.** On return the agent re-reads your current
  files instead of trusting stale memory, and if the working folder moved
  it warns and lets you re-pick or continue without it. See
  [Continue, Change Direction, and Return
  Later](../start-here/continue-and-return.md).

- **Trying a different angle.** Edit, try-same-prompt, or branch generate
  a second version that opens beside the first at equal width. For more
  than two arms, use the Workbench A/B surface. See
  [Working with Responses and
  Controls](../system-guide/responses-and-controls.md).

- **Research that has not converged.** Guidance mode offers next steps
  after alignment, and during deductive or inductive theory work.
  (planned)

- **Interrupted response.** On network failure the agent visibly retries
  and keeps what was already produced, including the partial answer. When
  retries run out, a retry-from-break-point action resumes from where it
  broke.

- **Holding a feature on for several turns.** The [Steer bar](../system-guide/steer-bar.md) holds skills you can press on rather than invoke once: a button darkens when active, fades over turns, drops off after about five; double-click locks it on.
