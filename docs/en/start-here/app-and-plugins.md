# The App and Plugins

Alt Theory comes in more than one form.

## The app

The desktop app is the whole product: the conversation interface, the
Understand/Work capability model, roles and knowledge bases, bundled
skills, approvals, imports, and settings. One install, no other tools
required. It is built for people who do not already live in an agent
harness.

## Plugins for your existing harness

If you already work in an agent harness (Pi, Claude Code, or another),
the plugin form brings Alt Theory's methods into the tool you already use:

- the bundled skills, unchanged, because skills are universal across
  harnesses
- an agent definition in your harness's own format, carrying Alt Theory's
  identity and principles
- optionally, a knowledge base you place where your harness can read it

What stays app-only is the product surface: the mode switch, the approval
interface, pickers, and imports, which your harness provides in its own
way. See
[Plugins and Capability Differences](../advanced/plugins-and-capability-differences.md).

## What the app is built on

The app's agentic engine is [Pi](https://pi.dev), an open agent harness.
This matters even if you never touch Pi directly:

- conversations are stored in a Pi-compatible format, so your work is not
  locked into Alt Theory
- skills follow ecosystem conventions, so skills you install work in both,
  and Alt Theory's skills work elsewhere
- conversations from other harnesses can be
  [imported](../system-guide/imports-and-continuity.md) and continued

## Choosing

- Most readers: use the app.
- Harness users who mainly want the methods: the plugin form.
- Both is a real option. The app for research conversations, the plugin
  where you already work. Materials and skills can be shared between them.
