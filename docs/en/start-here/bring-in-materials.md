# Bring in Your Materials and Context

The minimum you need to know about getting your materials into a
conversation.

## The pieces

- A conversation is where you and the agent think and work. It keeps its
  own history and configuration.
- A file attachment puts a specific file in front of the agent for this
  conversation. Drag it into the composer or use the attach button.
- A working folder (Work mode) is a folder on your computer the agent can
  work in: read files and create new ones. Attaching a folder defines
  where the practical work happens.
- A knowledge base is curated reference material. Enable it when its
  domain is relevant.

These compose: a conversation might have a draft attached, a project
folder as its working folder, and a knowledge base enabled, or none of
these.

## What the agent sees

The agent sees what you bring in: attachments, the working folder's
contents, the enabled knowledge base, plus what you write. It does not see
the rest of your computer. The composer area shows the working folder and
knowledge base for this conversation.

## Real files

Alt Theory reads the formats research uses: Word, PDF, Excel, PowerPoint.
Converted copies appear next to originals with a `_converted` suffix.
Images attach the same way; whether the agent can see them depends on the
model you chose. See
[Documents, Images, and Other Inputs](../system-guide/documents-images-inputs.md).

One convention: when the agent revises a document, it writes a copy or a
new, clearly-named file and tells you which. Your originals stay as they
were.
