# Understand and Work

Every conversation runs in one of two modes. The distinction is how much
of your computer and tool ecosystem you have opened to the agent. Both
modes are agentic.

## Understand

Careful dialogue with bounded reach.

- Works with the conversation, files you attach, the selected knowledge
  base, and its own knowledge, labelled.
- Does not browse the web, run commands, or roam your file system.
- No live lookup. When a claim would need verification, the agent says so
  and gives its best current understanding labelled by how solid it is:
  established, plausible but unverified, or unknown. It does not dress up
  memory as a search result.

Understand is a complete way to use Alt Theory, not a preview of Work.

## Work

Keeps the same conversational standard and adds practical reach:

- a working folder (and optionally more) where the agent can read and
  write project files
- live search and fetching: general web, academic search with verifiable
  metadata, and full-page retrieval
- document work: reading Word, PDF, Excel, PowerPoint, and producing new
  documents
- commands and installs, through a visible approval flow

Work carries the same standard into action. Consequential choices are
explained, provenance is kept, and your original files are never edited
in place.

## What asks for permission

- Inside attached working folders, the agent works without interrupting
  you for each step.
- Reading outside those folders, network access beyond the built-in search
  tools, and installing anything surface an approval request showing what
  is being asked and what you grant.

Full reference:
[Permissions, Approvals, and Agent Activity](../system-guide/permissions-approvals-agent-activity.md).

## Switching modes

Switch a conversation between Understand and Work at any time. The switch
applies from your next message. The conversation, reasoning, attached
materials, role, and knowledge base all carry across. Switching never
forks or resets anything.

## How to choose

Understand when you want the thinking and nothing else moved. Work when
the conversation should reach your files and the live world. Switch
whenever the answer changes.
