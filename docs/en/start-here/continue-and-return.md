# Continue, Change Direction, and Return Later

Research work is not linear. It pauses, branches, reverses, and picks up
weeks later. Alt Theory conversations are built for that.

## Conversations are durable

Every conversation is saved locally and appears in the conversation list,
grouped by working folder and searchable. Conversations name themselves
after the first exchange; rename them whenever you like. Reopen any
conversation and continue; its context, materials, mode, and
configuration resume with it.

## Changing direction

These controls are non-destructive: each opens a version beside the
original, which is never modified, so you can compare.

- Stop interrupts a response at any time.
- Edit an earlier message of yours reruns the discussion from that point
  with your new wording, to see whether a different framing changes the
  answer.
- Branch starts a related conversation to pursue a different direction
  against the same accumulated context.
- BTW opens a side conversation carrying your current context, for a
  tangent that should not clutter the main line.

[Working with Responses and Conversation
Controls](../system-guide/responses-and-controls.md) covers the comparison
pane these open into.

## Long conversations keep working

Long conversations eventually exceed what a model can hold in view at
once. When that nears, the app compacts the conversation: earlier turns
are summarized so the work can continue. A divider marks the boundary and
the summary is expandable. If something must not be lost to
summarization, put it in a file or a plan record; files do not compact.

## Returning after time away

Reopen a conversation after days or weeks and it resumes: history,
working folder, knowledge base, mode. Two things about the world outside
it are re-checked rather than assumed:

- If the working folder moved or was renamed, the app warns and lets you
  re-pick it or continue without it.
- If your files changed since you last worked here, the agent's first move
  on real work is to read the current files, not to trust its memory of
  them.

When a stage of a plan completes, re-align to refine what remains. See
[Think Better at Key Moments](../using-the-app/think-better-at-key-moments.md).
