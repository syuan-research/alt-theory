# Toolbox

The Toolbox is the small menu beside the composer: a short set of featured
actions covering the most common reasons to reach for something beyond
typing.

## The entries

- Ask how Alt works opens the [Helper](helper-and-guidance.md), the
  fresh-context assistant for questions about the app.
- Align on a plan or decision invokes the
  [aligning skill](bundled-skills.md#adaptive-aligning): the agent
  interviews you to build shared understanding before direction-setting
  work.
- Plan and record invokes the
  [plan-record skill](bundled-skills.md#adaptive-plan-record) for work
  worth tracking beyond one conversation.
- Look something up online (Work) invokes
  [live search](search-sources-web.md). In Understand this entry is not a
  disabled button: it is a line explaining that Understand has no live
  lookup and that switching to Work is how to search.
- All skills drops you into the [command palette](commands.md) with `/`
  pre-typed.

## Arming versus firing

Clicking a skill in the Toolbox or palette arms the composer with
`/name ` and focuses it, so you can type your question before it runs.
Only commands that need no prompt (`/new`, `/branch`, `/btw`, `/compact`,
`/helper`) fire on click.

## What the Toolbox is not

It is not the skill system, just a curated front door. Every entry has a
longhand equivalent (a command or a plain sentence), and everything not
featured here is one `/` away.
