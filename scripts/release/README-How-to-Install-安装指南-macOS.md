## English

### macOS: download and launch

1. Download `AltTheory-1.4.5-mac.zip`.
2. Unpack the complete `AltTheory` folder in Downloads. It contains
   `AltTheory.app` and `Fix-Open.command`.
3. Right-click `Fix-Open.command`, choose **Open**, then confirm **Open**.
4. Open `AltTheory.app`. Go to **System Settings → Privacy & Security → Open
   Anyway**, authenticate, and confirm **Open**. Move it to Applications if desired.

Alternatively, run
`xattr -dr com.apple.quarantine "$HOME/Downloads/AltTheory/AltTheory.app"` in
Terminal; replace the path if needed. Use either fix only for this release's
ZIP. Apple Silicon only. Node.js and npm are not required.
`BUILD-INFO-mac.txt` carries the SHA-256.

## 简体中文

### macOS：下载与启动

1. 下载 `AltTheory-1.4.5-mac.zip`。
2. 在「下载」中完整解压 `AltTheory` 文件夹；里面有 `AltTheory.app` 和
   `Fix-Open.command`。
3. 右键 `Fix-Open.command`，选择 **打开（Open）**，再确认一次。
4. 打开 `AltTheory.app`。前往 **系统设置 → 隐私与安全性 → 仍要打开（Open
   Anyway）**，验证身份后确认 **打开（Open）**。需要时再移到「应用程序」。

也可在终端运行
`xattr -dr com.apple.quarantine "$HOME/Downloads/AltTheory/AltTheory.app"`；
路径不同时请替换。仅对本 Release 的 ZIP 使用这些方法。仅支持 Apple
Silicon。使用打包应用不需要 Node.js 或 npm。SHA-256 见
`BUILD-INFO-mac.txt`。

## 繁體中文（香港）

### macOS：下載與啟動

1. 下載 `AltTheory-1.4.5-mac.zip`。
2. 在「下載」中完整解壓縮 `AltTheory` 資料夾；裡面有 `AltTheory.app` 和
   `Fix-Open.command`。
3. 右鍵 `Fix-Open.command`，選擇 **開啟（Open）**，再確認一次。
4. 開啟 `AltTheory.app`。前往 **系統設定 → 私隱與保安 → 仍要開啟（Open
   Anyway）**，驗證身份後確認 **開啟（Open）**。需要時再移到「應用程式」。

也可在終端運行
`xattr -dr com.apple.quarantine "$HOME/Downloads/AltTheory/AltTheory.app"`；
路徑不同時請替換。只對本 Release 的 ZIP 使用這些方法。僅支援 Apple
Silicon。使用打包應用毋須 Node.js 或 npm。SHA-256 見
`BUILD-INFO-mac.txt`。
